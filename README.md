# 工程で切る、AI引き継ぎ診断

**AIに渡すのは業務じゃない、工程です。**

管理職の5業務（週報の取りまとめ／会議資料の作成／評価コメント／稟議・申請書／部門数字の説明）を
工程に分解し、「AIに渡せる工程」と「自分に残す工程」の線を引く診断ツールです。

**▶ https://wison-blip.github.io/ai-work-reduction-diagnosis/**

DMM 生成AI CAMP 第21回コンペ 提出作品

## 構成

- `index.html` — 単一HTMLファイル1枚。これがすべてです。
- 外部API・外部通信なし。CDNからのライブラリ読み込みもありません（依存ゼロ）。
- 回答はブラウザ内でのみ処理され、送信も保存もされません。

## 特徴

- 業務単位ではなく **工程単位で削減時間を積み上げる**（AI代替率0の工程は削減ゼロで固定）
- 工程比率・AI代替率・実効率を **画面上にすべて開示**
- 選んだ業務の設問だけを出題（最短6問／最長12問・3分以内）
- 最優先の1業務について、工程分解・削れない工程の説明・**コピペで使えるプロンプト**まで提示
